# Aplicativo Mobile - Geração de Guias INSS

Aplicativo React Native para geração automatizada de guias do INSS.

## Requisitos

- Node.js (versão 14 ou superior)
- npm ou yarn
- Expo CLI

## Instalação

1. Instale as dependências:
```bash
npm install
# ou
yarn install
```

2. Inicie o aplicativo:
```bash
npm start
# ou
yarn start
```

## Estrutura do Projeto

- `/src/screens`: Telas do aplicativo
- `/src/components`: Componentes reutilizáveis
- `/src/services`: Serviços de API e integrações
- `/src/context`: Contextos React para gerenciamento de estado
- `/src/utils`: Funções utilitárias
- `/src/assets`: Imagens, fontes e outros recursos

## Funcionalidades

- Cadastro e login de usuários
- Seleção de categoria de contribuinte
- Solicitação de geração de guias
- Visualização e download de guias geradas
- Pagamento via Pix
- Histórico de guias e pagamentos
